# operit-plugin-dev-skill

用于指导开发 Operit app 插件。

## 包含的技能

- [skills/operit-plugin-dev-skill/](skills/operit-plugin-dev-skill/) — **Operit 插件开发技能**：在任意桌面环境（Windows / macOS / Linux）指导开发 Operit 插件，以官方 ToolPkg 为范例，使用与官方 app 协调的 Compose DSL UI（MaterialTheme），正确注册侧边栏入口并使用官方 Operit API。

## 使用方式

将 `skills/operit-plugin-dev-skill/` 目录作为 任意 Agent skill 使用，详见其 [README](skills/operit-plugin-dev-skill/README.md)。

## 权威来源

Operit 源码 / API 最终权威：官方 GitHub 仓库 `https://github.com/AAswordman/Operit`。
